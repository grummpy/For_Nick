    FIVE-MINUTE SETUP

    Connect your OpenAI assistant

    1. Copy .env.example to .env.
    2. Add an API key from platform.openai.com.
    3. Optional: create a Vector Store, upload your source files, then add its ID as OPENAI_VECTOR_STORE_ID.
    4. Run npm run dev and open the local address.

    Your key stays on your machine and is never sent to the browser. Full details are in the README.
